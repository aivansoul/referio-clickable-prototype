# Figma asset crop map

These PNG assets are lossless crops of the local Figma reference boards. Coordinates use ImageMagick geometry notation `WIDTHxHEIGHT+X+Y`, measured from the top-left corner of each 2400 x 1792 source image.

No icon was redrawn, generated, recolored, or resampled. Each crop retains the original source pixels with 8 px of surrounding board background; only ancillary metadata was stripped and PNG compression was increased.
